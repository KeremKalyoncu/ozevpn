# Proje Bağlamı — OzeVPN v6

- **Ürün / mevcut repo / commit:** OzeVPN v6 (`github.com/KeremKalyoncu/ozevpn`, `main`, baseline `88a5427`) — Windows tek-dosya masaüstü VPN & sansür aşım uygulaması (`dist/OzeVPN.exe`, `57.4 MB`).
- **Yeni proje mi, iyileştirme mi:** Mevcut çalışan uygulamanın görsel, ergonomik ve teknik kalite iyileştirmesi.
- **Hedef kitle ve 3 kritik görev:** Türkiye'deki oyuncular ve gündelik masaüstü kullanıcıları. (1) Tek tıkla `Oyun TUN` + `WARP WireGuard (TCP+UDP)` bağlantısı (Roblox/Discord), (2) Canlı erişim / hız testi ve `Site Kurtarıcı`, (3) Bölünmüş tünel kuralları (TR bankalar/4K video bypass) ve güvenlik anahtarları (Reklam Kalkanı, Kill Switch, LAN izolasyonu).
- **Rotalar ve veri/API sözleşmeleri:** `/` (panel), `/auth?t=<64hex>`, `/proxy.pac`, `/api/config` (GET/POST), `/api/status`, `/api/netinfo`, `/api/install/status`, `/api/install/setup`, `/api/connect`, `/api/disconnect`, `/api/reload`, `/api/relaunch-admin`, `/api/emergency-reset`, `/api/new-identity`, `/api/probe`, `/api/speedtest`, `/api/rescue`, `/api/shutdown`, `/api/export/openwrt`, `/api/healthz`, `/api/metrics`.
- **Marka / onaylı görseller / mevcut DESIGN.md:** Özgün OzeVPN kalkan logosu (`web/favicon.svg`), koyu/açık tema destekli. Anayasa: `docs/frontend-craft/DESIGN.md` (Yön B onaylı).
- **Framework, sürüm, paket yöneticisi, primitive ailesi:** Go `1.26` (`embed.FS`), sıfır dış frontend bağımlılığı, saf HTML5 + CSS3 + Vanilla JS (`web/`). Paket yöneticisi / bundler kullanılmaz.
- **Mevcut token, font, ikon ve bileşenler:** CSS custom properties (`:root[data-theme="dark"|"light"]`), sistem yerel fontları (`Segoe UI Variable` / `Cascadia Mono`), Lucide-stil `1.75px` inline SVG sprite, native HTML kontrolleri + CSS switch + erişilebilir modal/tabs/toast.
- **Desteklenen cihaz/browser/locale/tema:** Windows 10/11 Edge/Chrome `--app` penceresi (`1180×820`), geniş masaüstü (`1440×900`), dar/mobil görünüm (`390×844`), `tr-TR` (LTR), Dark & Light tema (`prefers-color-scheme` + `localStorage`).
- **Performans bütçesi ve mevcut saha verisi:** `TestWebUIBudgetAndAccessibilityContract` katı üst sınırı `<= 120 KB` toplam gömülü frontend varlığı; yerel `127.0.0.1` yükleme `<100 ms`, 0 harici ağ isteği. Saha CWV verisi: `UNKNOWN` (yerel 127.0.0.1 masaüstü uygulaması; yalnızca lab/Edge CDP verisi geçerlidir).
- **Hukuk, erişilebilirlik hedefi, varlık lisansları:** WCAG 2.1 AA hedefi, `THIRD_PARTY_LICENSES.md` (`sing-box` GPL-3.0, `Tor`/`lyrebird` BSD-3-Clause), Lucide-stil inline SVG ikonlar (ISC/özgün), sıfır telemetri (`PRIVACY.md`).
- **MCP/CLI erişimi, yerel URL:** Yerel `127.0.0.1:7788` (audit) / `127.0.0.1:7777` (varsayılan), Microsoft Edge Chromium CDP + `go test -race ./...` + `scorecard.py`.
